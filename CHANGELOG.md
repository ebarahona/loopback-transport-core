# Changelog

## Changelog

All notable changes from the first published release onward are documented here. Pre-release work happened on the `0.0.0` development branch and is not retroactively listed.

This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Entries are generated by [release-please](https://github.com/googleapis/release-please) from [Conventional Commits](https://www.conventionalcommits.org/).

## Unreleased

### Features

- discovery: add HandlerDiscoverer extension point allowing plugins to contribute custom decorator vocabularies (@messageHandler and @eventHandler now ship as default discoverers)
- discovery: add DiscoveryService for universal enumeration of every discovered transport handler (NestJS DiscoveryService parity)
- discovery: add HandlerKind open string type with HANDLER_KIND_REQUEST / HANDLER_KIND_EVENT constants for forward-compatible custom kinds
- discovery: allow HandlerDiscoverer.discover() to return DiscoveredHandler[] | Promise<DiscoveredHandler[]> for async metadata sources
- serializers: add SERIALIZER_TAG / DESERIALIZER_TAG extension points and ServerBase.resolveSerializer for tag-based serializer pluggability (third extension axis alongside transport servers and handler discoverers)
- discovery: DiscoveryService now enumerates serializers via getSerializers / getDeserializers / getSerializerForTransport / getDeserializerForTransport
- interfaces: TransportServer.resolveSerializer is a required interface member (ServerBase provides the default tag-based implementation); the lifecycle observer no longer duck-types the method
